# Roll Dice

Cuando el usuario pida lanzar un dado:

1. Identifica cuántas caras tiene.
2. Genera un número aleatorio entre 1 y el número de caras.
3. Comprueba que el resultado esté dentro del rango.
4. Muestra el resultado claramente.
5. Nunca inventes el resultado.
